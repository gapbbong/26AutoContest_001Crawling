# 📚 [교육-001] 기출 문제 크롤링 및 단원별 기출정리집 문서 자동 생성기

> **2026년 부산광역시교육청 업무자동화 프로그램 개발대회 출품작**  
> **과제번호**: 교육-001 (선정과제 가점 1점 대상)  
> **분야**: 교육  

---

## 1. 개발 배경 및 목적
* **현행 업무의 문제점**: 
  * 중·고등학교 교사들이 내신 대비, 방과후 수업, 학력평가 피드백용 기출정리집을 제작할 때 여러 포털에서 PDF/HWP를 다운로드하여 직접 문항을 자르고 붙이는 작업에 매회 **3~5시간 이상의 단순 반복 노동**이 소요됨.
  * 단원별 분류, 서식 정렬, 배점/정답/해설 매칭 과정에서 오탈자 및 편집 오류가 빈번히 발생함.
* **자동화 개선 효과**:
  * 공신력 있는 공공 기출 데이터(EBSi, 평가원)를 기반으로 **원하는 단원·과목·연도만 스마트 필터링**.
  * **원클릭으로 학생용 문제지, 교사용 문제지(정답/배점 표기), 정답 및 해설집 3종의 한글(HWPX) 표준 문서를 1분 이내에 자동 조판**.
  * 교원의 불필요한 편집 행정 업무를 경감하고 수업 연구에 집중할 수 있는 환경 조성.

---

## 2. 주요 기능 및 특징
1. **공공 기출 실시간 크롤러 (EBSi·평가원·부산교육청 3개 출처 동시 연동)**:
   * **초기 설정 시 3개 공공 교육 포털이 기본 전체 선택**되어 원클릭으로 일괄 수집
   * 연도(2021~2026), 학년(중1~중3, 고1~고3), 시험구분, 과목을 선택하여 최신 기출문제 실시간 크롤링
2. **원스톱 한글(HWPX) 자동 조판 & 다운로드**:
   * 크롤링 완료 즉시 **학생용 문제지**, **교사용 정답표기 문제지**, **상세 해설집** 3종의 HWPX 표준 문서 자동 생성 및 다운로드
3. **실시간 2단 시험지 조판 미리보기**:
   * 크롤링된 문제의 수식(LaTeX/MathJax), 배점, 정답률, 해설을 웹에서 2단 표준 시험지 형태로 실시간 확인
4. **학교 보안망 & 오프라인 완벽 호환**:
   * 로컬 SQLite3 DB 캐싱 기반으로 인터넷 연결이 제한된 교내 업무망 환경에서도 무결점 고속 구동

## 3. 프로그램 실행 방법
### 간편 실행 (Windows 11 / 10):
1. `실행하기.bat` 더블 클릭
2. 자동으로 브라우저가 열리며 웹 인터페이스 실행

### 수동 실행:
```bash
python main.py
```

## 4. 심사 기준 대응 요약 (100점 만점)
* **창의성 (20점)**: 단순 다운로드가 아닌 단원별 큐레이션 및 3종 HWPX 자동 조판 시스템
* **활용성 (20점)**: 시험지 제작 시간 99% 단축 (3시간 → 10초), 교사용/학생용 분리 생성
* **완성도 (20점)**: 직관적인 웹 GUI, 실시간 2단 미리보기, 오류 방지 로직
* **일반성 (20점)**: 부산 전 학교/전 과목 확장 가능한 메타데이터 구조, 유료 라이선스 제로
* **확장성 (20점)**: 모듈형 크롤러 어댑터 패턴(`BaseCrawler`), 개방형 HWPX 빌더 구조
